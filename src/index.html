  1. 1

    Find the game

Hook controls

Turning the hook off makes the game launch normally. Nothing gets deleted, so you can turn it back on any time.

Not connecting?

  • Load into an actual level. The main menu doesn't count.
  • Hyperballin is on Unreal 5.8, which is very new. If UE4SS doesn't support it yet, the game opens without the hook. Reinstall once a newer UE4SS build is out.
  • Windows Defender sometimes quarantines dwmapi.dll. Check Protection history.
